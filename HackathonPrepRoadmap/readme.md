# Hackathon Preparation Roadmap (For Me)

> Goal:
> Become comfortable enough to participate in hackathons confidently, contribute in teams, help others, and slowly move toward leadership/team coordination roles.

---

# 1. Git & GitHub (Most Important First)

## Why?
Hackathons are team-based. Without GitHub collaboration, teamwork becomes messy.

## Learn These Basics First

### Git Basics
- What is Git?
- What is version control?
- Difference between Git and GitHub

### Important Commands
- `git init`
- `git clone`
- `git status`
- `git add`
- `git commit`
- `git push`
- `git pull`

### Branching
- What are branches?
- Create a branch
- Switch branches
- Merge branches

### Collaboration Flow
- Pull Requests (PR)
- Forking repositories
- Reviewing changes
- Solving merge conflicts

### GitHub Workflow
- Creating repositories
- Organizing repositories
- Writing proper README files
- Uploading projects
- Managing issues/tasks
- Using `.gitignore`

## Practice Tasks
- Push 3 small projects on GitHub
- Create branches manually
- Merge your own branches
- Simulate team workflow alone
- Create a clean profile README

# 15. My First Hackathon Goals

- Understand hackathon environment
- Talk with new people
- Contribute to a team
- Push code properly
- Help in deployment/documentation
- Learn team workflow
- Finish something usable
- Gain confidence

Winning is NOT the first goal.

# Final Reminder

I do NOT need to know everything before entering hackathons.

I only need:
- willingness to learn,
- ability to contribute,
